# B站自动点赞

在 B 站看视频时，只要是**已关注 UP 主**的视频，打开就自动点个赞。
跑在 Android 手机上，不用 root、不用电脑、不用 ADB、不用填 Cookie。

脚本不放在仓库里。去 [Releases](https://github.com/1330980637/BiliAutoLike/releases) 下载：`BiliAutoLike-v1.1.0.apk` 装了就能用，或者下载 `bili-autolike.js` 自己在 AutoX 里跑。

## 功能

- 打开已关注 UP 的视频，1 秒内点赞，只点一次
- 竖屏视频页、横屏全屏播放器都支持
- 自己手动取消的赞不会马上补回来（24 小时内不管），超过 24 小时再看会重新点赞
- 横屏锁屏时不硬点：B 站锁屏后按钮被隐藏，脚本安静等着，等你解锁再干活
- 合作视频也能认：创作团队里有你已关注的 UP 就算
- 重复运行不打架：新实例启动会先停掉旧的
- 有常驻通知和日志文件，出问题能查

## 实现方法

整体思路：**不碰接口，纯靠无障碍读界面 + 点控件**，所以不需要登录、不需要 Cookie，也不会有风控登录的问题。

1. **怎么知道在视频页**：看有没有点赞按钮。首页推荐流没有这个按钮，所以不会误点。
2. **竖屏怎么点**：点赞按钮 id 是 `tv.danmaku.bili:id/frame_like`，已赞时 `checked=true`。
3. **横屏怎么点**：横屏全屏播放器里没有 `frame_like`，按钮是一个 desc 为 `点赞2925` 的可点击控件；点完之后 desc 变成 `取消点赞2926`。所以**看 desc 前缀判断状态，不看赞数**——赞数上万会显示成「2.9万」，加一减一根本看不出来。
4. **锁屏怎么办**：锁屏后 B 站把整个控制层隐藏，元素树里只剩 `bbplayer_fullscreen_lockscreen_off_left/right` 两个锁图标。脚本识别到就跳过，不会乱点。
5. **怎么判断已关注**：竖屏看 `follow` 按钮的 desc（「取消关注，按钮」）或页面上的「已关注」。横屏播放器没有关注按钮，只能靠记忆里的 UP 名单：竖屏进过这个 UP 的视频就会记住，启动时也会从历史点赞记录里补回来。
6. **怎么去重**：给每个视频算一个 key，三级兜底：BV 号 → UP 名 + 标题 → UP 名 + 按钮位置。
7. **怎么防误操作**：点完等 1.8 秒再读一次状态确认；点过赞的视频又变成未赞，记 24 小时观察期，期间不再碰。
8. **一个坑**：横屏全屏播放时，`currentPackage()` 返回的是 `com.android.systemui` 而不是 `tv.danmaku.bili`，所以不能只看包名判断，要看有没有点赞按钮。
9. **怎么跑起来**：AutoX.js v7 执行 JS，主循环 400ms ~ 1.2s 轮询一次；用锁文件 + 心跳保证只有一个实例；每 60 秒写一行心跳日志，方便看出是不是被系统冻死了。

## 怎么用

**方式一：直接装 APK**（省事）

1. 从 [Releases](https://github.com/1330980637/BiliAutoLike/releases) 下载 `BiliAutoLike-v1.1.0.apk` 安装
2. 打开它，按提示开启无障碍服务和「所有文件访问」权限
3. 打开 B 站看视频，效果和下面一样

**方式二：用 AutoX.js 跑脚本**（方便自己改）

1. 装 [AutoX.js](https://github.com/aiselp/AutoX) v7，开启无障碍服务和存储权限
2. 从 [Releases](https://github.com/1330980637/BiliAutoLike/releases) 下载 `bili-autolike.js`，放到手机任意英文路径，例如 `/sdcard/Download/DSH-Go/`
3. 在 AutoX 里打开脚本 → 运行，看到「自动点赞 v7.1 已启动」和常驻通知就生效了
4. 想停：在 AutoX 运行列表里停，或者下拉通知栏 →「Autox.js保持运行中」→ 停止所有脚本

> 手机要亮屏、B 站要在前台才会工作；AutoX 被系统清掉后需要重新运行脚本。

## 可调参数

脚本顶部 `CONFIG`：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `USER_HOLD_MS` | 24 小时 | 掉赞后多久才允许重新点赞 |
| `FAIL_COOLDOWN_MS` | 5 分钟 | 点了但没确认成功，这个视频冷却多久 |
| `LOOP_FAST_MS` / `LOOP_IDLE_MS` | 400 / 1200 ms | 轮询间隔 |

状态存在 `bili-autolike-state.json`，删掉就全部重置（包括记住的已关注 UP）。
日志在 `bili-autolike.log`，排错用的界面转储在 `bili-autolike-dump.txt`。

## 已知限制

- 横屏没有「已关注」字样，只能靠记忆；没在竖屏进过的 UP，横屏认不出来（不会乱点，会写进日志）
- 横屏锁屏时完全不工作，这是故意的（尊重锁屏）
- AutoX 自带的「打包成 APK」直接产出的包缺少原生库，可能装不上；本项目 Release 里的 APK 是重新签名处理过的，已在真机装上
- 只保证在本项目开发的机型上验证过（华为 BRE-AL80 / Android 12），B 站换控件 id 后需要跟着改

## 风险提示

自动化点击有可能违反 B 站用户协议，账号存在被风控的可能。本项目仅用于学习，请自行评估，账号异常与本项目无关。
